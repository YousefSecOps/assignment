Student Assignment

1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open validation.html in a browser to test the registration form.
4. Click "Go to Data Table" to test search and sorting.

Files:
- validation.html: Registration form
- data.html: Data table
- style.css: Page design
- js/App.js: Form validation
- js/data.js: Table, search, and sorting
